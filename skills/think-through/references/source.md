# Source and adaptation

This skill is an English adaptation of the user's six-page thinking-tools framework, supplied as `1-Framework-myslenia.pdf`, dated 19 October 2026. The PDF remains the authority for the framework's meaning. An unchanged copy is archived in the source repository for maintainers; it is not included in installed skills or the plugin payload and is not needed during normal use.

Maintainer-only archive: `docs/sources/thinking-framework-2026-10-19.pdf` in the source repository. Its original filename, date, page count, and SHA-256 are recorded in `docs/sources/thinking-framework.json`. These are source-repository locations, not paths to resolve inside a client installation. Consult the archive only for a requested source audit, translation maintenance, or a suspected mismatch; use the English instructions during ordinary operation.

Conversational routing and chat-first interaction are integration choices requested by the user. Later feedback adds replies in the user's language, a brief initial method name without its PDF number, immediate first-round steps, and follow-up on a critical unverified assumption. The maintained skill files remain English.

The analysis map is a further user-requested presentation extension: expose evidence and its basis, the blocking unknown, and a next step that would resolve it; update after material evidence and skip simple answers. It replaces compulsory comparisons of nearby methods with attention to the actual obstacle and next step. Method comparisons remain available when useful or requested. Unsolicited recall practice is no longer suggested; the agent still performs the source's reconstruction and changed-case prediction checks. This user-directed interaction change does not remove predictions, competing hypotheses, discriminating tests, or evidence safeguards. Completion information can appear once in the map rather than in a duplicate summary. `show-me` is an optional capability, not a dependency.

These extensions are not requirements attributed to the PDF or evidence of improved human understanding or answer quality. Examples can be condensed; mathematical representations can be offered as equivalent aids, not additional required steps. When maintaining the skill, compare all routes, instructions, outputs, and caveats with the PDF; preserve explicit user-requested interface additions separately. The PDF describes an authored synthesis of methods, not an independently tested framework. Its cited sources have different scopes and do not establish that this complete workflow has been validated. Behavioral examples used to check this skill establish only the behavior observed in those examples.
